Set up OpenHotel

This server has an empty database and no accounts, so nothing is configured yet. Answer a few questions here instead of setting environment variables. It takes about five minutes.

The server prints a one-time code in its log when it starts empty. This keeps strangers from setting up your server first.

Steps

    Pick a mode and the steps for it show here. You answer one step at a time, then check everything before anything is saved.

    Changing mode later

    The mode is fixed once setup ends. Switching between standalone, network and managed wipes accounts and links, so it is not in the interface. It takes a server command that asks you to type the hotel name to confirm.
