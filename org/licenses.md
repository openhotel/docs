## Known inconsistencies
- pixi-components `package.json` says `NC BY-SA 4.0`, LICENSE file is CC BY-SA 4.0.
- web-components `package.json` says `NC BY-NC-SA 4.0` (typo of CC BY-NC-SA).
- pixi-components and web-components README badges point to `openhotel/components` (old name).
- asset-editor README build badge points to `openhotel/auth`.

## What CC BY-NC-SA means here (from openhotel README)
Free to use and remix, no commercial use, credit the repo, keep the license. Exceptions: donations to run a server with a cosmetic badge only; marketing exceptions need explicit permission.
